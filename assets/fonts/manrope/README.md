# Manrope

Selected by Akila on 28/10/2026 (Option B, display headings). Variable upright font, weights 200–800.

Source: https://github.com/google/fonts/tree/main/ofl/manrope
Licence: SIL Open Font License 1.1; see OFL.txt.

The full-coverage variable WOFF2 is served locally through generated css/tokens.css
and precached for offline use. The original TTF remains the build source; it is
not downloaded or precached by the application. System fonts remain the fallback.

Rebuild with fonttools[woff]==4.63.0 (build-time only):
`python -m fontTools.ttLib.woff2 compress INPUT.ttf -o OUTPUT.woff2`.
Run `python scripts/verify-fonts.py` from the repository root to compare all glyphs,
variation and layout tables with the TTF sources. No subsetting is performed.
The original OFL.txt, copyright notices and font names remain unchanged.
